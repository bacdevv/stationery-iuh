# Stationery IUH

## Giới thiệu

**Stationery IUH** là giao diện web bán văn phòng phẩm với phong cách hiện đại, hiển thị mượt mà trên mọi kích thước màn hình. Dự án sử dụng HTML, CSS, JavaScript, tập trung vào bố cục đẹp, chuyển cảnh rõ ràng và trải nghiệm mua sắm trực quan.

---

## Điểm nổi bật

* **Trang chủ:** Có banner nổi bật và hiển thị các danh mục phổ biến.
* **Danh sách sản phẩm:** Trình bày gọn gàng, dễ dàng theo dõi giá gốc và giá giảm.
* **Đầy đủ tính năng:** Bao gồm các trang Product, Stationery Product, Cart, Wishlist và Login.
* **Responsive:** Hoạt động trơn tru trên các thiết bị Mobile, Tablet và Desktop.

## Hướng dẫn chạy nhanh

1. **Mở thư mục** project bằng trình soạn thảo (ví dụ: VS Code).
2. **Chạy Live Server** với tệp `index.html`.
3. **Khám phá** toàn bộ các trang con nằm trong thư mục `assets/pages/`.

## Extensions đề nghị (VS Code)

* **Live Server:** Chạy nhanh trang HTML trực tiếp trên trình duyệt.
* **Prettier - Code formatter:** Định dạng mã nguồn đồng nhất và gọn gàng.
* **HTML CSS Support:** Gợi ý các class/id CSS ngay trong tệp HTML.
* **HTML Snippets:** Cung cấp các mẫu HTML có sẵn để viết code nhanh hơn.
* **CSS Peek:** Nhảy nhanh tới phần định nghĩa CSS từ tệp HTML.
* **JavaScript (ES6) code snippets:** Gợi ý các cú pháp JavaScript hiện đại.
